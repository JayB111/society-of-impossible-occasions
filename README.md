# The Society of Impossible Occasions

*Some things deserve a beautiful ending.*

## Project Overview

A Java SE Event Management Application developed as part of the Lexicon Java course.

The application is based on a fictional society that organises unusual and humorous events, including A Funeral for Your Bad Decisions.

## Project Objectives

- Manage events.
- Register participants.
- Manage invitations and invitation statuses.
- Prevent duplicate invitations.
- Prevent event overbooking.
- Store and retrieve data using a relational database.

## Technologies

- Java 21
- Maven
- MySQL
- JDBC
- JUnit
- Git and GitHub

## Project Structure

| Package | Responsibility |
|---|---|
| config | Database connection |
| controller | Application flow |
| dao | Database operations |
| exception | Custom exceptions |
| model | Domain classes |
| service | Business logic |
| view | Console interface |
